GreekTube Audio Helper — Οδηγίες
=================================

Τι κάνει
--------
Κατεβάζει τον ήχο ενός YouTube βίντεο σε MP3 απευθείας στον υπολογιστή.
Η εφαρμογή ανοίγει ως ιδιωτική σελίδα στο 127.0.0.1 και δεν χρησιμοποιεί
cloud downloader ή εξωτερικά fonts.

ΠΡΩΤΗ ΦΟΡΑ
----------
1. Χρειάζεται Python 3.10 ή νεότερο από https://www.python.org/downloads/
   Στην εγκατάσταση επίλεξε "Add Python to PATH".
2. Κάνε διπλό κλικ στο setup.bat.
3. Το setup κατεβάζει το επίσημο yt-dlp.exe και επαληθεύει το SHA-256 του.
4. Χρειάζεται επίσης FFmpeg. Αν δεν βρίσκεται ήδη στο PATH βάλε το
   ffmpeg.exe μέσα στον φάκελο bin και ξανατρέξε το setup.bat.

ΚΑΘΗΜΕΡΙΝΗ ΧΡΗΣΗ
----------------
1. Κάνε διπλό κλικ στο start.bat.
2. Ανοίγει αυτόματα η ιδιωτική σελίδα http://127.0.0.1:8756/
3. Επικόλλησε το YouTube link.
4. Πάτησε «Λήψη MP3».
5. Το MP3 αποθηκεύεται στον φάκελο Λήψεις.
6. Για τερματισμό κλείσε το μαύρο παράθυρο.

ΑΝ ΤΟ YOUTUBE ΖΗΤΗΣΕΙ ΕΠΙΒΕΒΑΙΩΣΗ
---------------------------------
Η σελίδα θα εμφανίσει το κουμπί «Δοκιμή με Firefox session».
Η επιλογή χρησιμοποιεί το υπάρχον Firefox session μόνο τοπικά. Δεν εξάγει
και δεν αποθηκεύει cookies. Προτίμησε δευτερεύον YouTube account.

ΑΣΦΑΛΕΙΑ
--------
- Ο server ακούει μόνο στο 127.0.0.1.
- Κάθε εκκίνηση δημιουργεί νέο ιδιωτικό session token.
- Ξένα tabs και μη εξουσιοδοτημένα local requests απορρίπτονται.
- Το link περνά στο yt-dlp ως ξεχωριστό argument χωρίς shell execution.
- Επιτρέπονται μόνο κανονικά youtube.com και youtu.be links.
- Δεν υπάρχει upload κώδικας ή αποθηκευμένο secret.
- Το UI λειτουργεί χωρίς κανένα εξωτερικό web request.

Κατέβασε μόνο περιεχόμενο που έχεις δικαίωμα να χρησιμοποιήσεις.

ΠΡΟΒΛΗΜΑΤΑ
----------
- «Δεν βρέθηκε Python» → εγκατέστησε Python 3.10+ και ξανατρέξε setup.bat.
- «FFmpeg δεν βρέθηκε» → βάλε ffmpeg.exe στον φάκελο bin.
- Η λήψη απέτυχε → άνοιξε «Εμφάνιση log» για το τοπικό μήνυμα.
- Παλιό yt-dlp → ξανατρέξε setup.bat για ασφαλή ενημέρωση.
